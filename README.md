# lab16v2: LINQ - фільтри, join, агрегації. Продуктивність

Лабораторна робота №10 з дисципліни «Об'єктно-орієнтоване програмування».  
**Виконав:** Ярмошик, група ІПЗ-3/1  
**Варіант:** 2 (Управління студентами)

## Вимоги та запуск
Python 3.10+, зовнішні бібліотеки не потрібні.
```bash
cd lab16v2
python main.py
```

## Структура
| Файл | Призначення |
|---|---|
| `models.py` | Сутності `Student`, `Course` |
| `data.py` | Тестові дані (20 студентів, 10 курсів) і генератор великих наборів |
| `queries.py` | Чотири запити варіанту у двох стилях + неефективні варіанти для порівняння |
| `main.py` | Запуск, вимірювання часу (`perf_counter`, аналог `Stopwatch`), порівняння |
| `Report.md` | Звіт: дані, вивід, висновки, відповіді на контрольні запитання |

## Запити за варіантом
1. Студенти віком до 20 років на курсі «Programming Basics».
2. Join студентів із курсами (ім'я студента, назва курсу).
3. Кількість студентів на кожному курсі.
4. Наймолодший студент.

## Відповідність синтаксисів
У Python немає двох синтаксисів LINQ, тому:
- **синтаксис запитів** = декларативні вирази-генератори й comprehension;
- **синтаксис методів** = функціональний стиль (`filter`, `map`, `min`, `Counter` з `lambda`).
